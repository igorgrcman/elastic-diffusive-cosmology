## 1. NAMING PRINCIPLES

### 1.1 Core Philosophy

In Elastic-Diffusive Cosmology, observable "particles" are **topological states of the 5D brane**—junction defects, loop excitations, and mode couplings. The EDC framework derives physics from geometry, not from imposed symmetry groups or force carriers.

### 1.2 What Counts as "EDC-Native"

A term is **EDC-native** if it describes:
1. **Topological structure** (junction, loop, winding, homotopy class)
2. **Geometric property** (coordination, contact area, Steiner angle)
3. **Dynamical process** (tunneling, release, pinning, frustration)
4. **5D origin** (brane tension, bulk mode, boundary condition)

A term is **NOT EDC-native** if it:
1. Refers to 3D/4D Standard Model constructs (quarks, gluons, gauge bosons)
2. Presupposes SM force structure (strong/weak/electromagnetic)
3. Uses SM-derived quantum numbers (isospin, strangeness, charm)
4. References SM-specific models (shell model, liquid drop, bag model)

### 1.3 Policy Lock Sentence

> **This chapter uses EDC-native terminology exclusively. Conventional particle
> names appear only in Appendix X (analogies) and Appendix Q (calibration).
> See the Glossary for term definitions.**

Use macro: `\EDCPolicyLockSentence`
