## WRITING STYLE PRINCIPLES

1. **Physical picture before formalism**
   - Always explain WHAT before HOW
   
2. **Clear epistemic status**
   - [BL], [D], [Dc], [I], [P] tags on every claim
   
3. **Forward/backward references**
   - "This will be derived in Ch X"
   - "Recall from Ch Y that..."
   
4. **Worked examples**
   - Numerical values throughout
   - Show the calculation
   
5. **Visual aids**
   - Diagrams for physical processes
   - Flowcharts for derivation logic
   - Tables for parameter ledgers
