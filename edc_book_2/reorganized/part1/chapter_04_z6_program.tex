\subsection{Why Exactly Three}

\begin{statusbox}{{Three Generations: Not Four, Not Two}}
\textbf{Geometric necessity} \tagP{}:
\begin{itemize}[nosep]
\item $Z_3$ has \textit{exactly} 3 elements
\item Each element labels one generation
