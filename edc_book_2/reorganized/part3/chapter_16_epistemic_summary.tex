\section{Introduction: Transparency Over Certainty}
\label{sec:epis_intro}
% ════════════════════════════════════════════════════════════

Science progresses through honest assessment of what we know and don't know.
This chapter applies the epistemic framework (see Preface) to summarize
the status of all major claims in this book.

\textbf{Recall the tag definitions}:
\begin{itemize}[nosep]
\item \tagM{}: Pure mathematics (absolutely certain)
\item \tagP{}: Postulate (assumed, testable by consequences)
\item \tagDer{}: Derivation (follows from [M] and [P])
\item \tagDc{}: Conditional derivation (requires reduction dictionary)
\item \tagI{}: Identification (pattern match without derivation)
\item \tagCal{}: Calibration (fitted to data)
\item \tagBL{}: Baseline (empirical measurement)
\item \tagOpen{}: Open problem (unresolved)
\end{itemize}

\section{Falsification Criteria}
\label{sec:falsification}
% ════════════════════════════════════════════════════════════

\subsection{What Would Falsify EDC}

The framework would be \textbf{falsified} if:

\begin{enumerate}
\item \textbf{Geometric predictions fail after error closure}:
After calculating all [Open] corrections, if residual deviation
exceeds $3\sigma$ with no plausible $C_{\text{red}}$.

\item \textbf{Structural incompatibility discovered}:
E.g., if a 4th generation is found (contradicts $Z_3$).

\item \textbf{Multiple simultaneous failures}:
If several independent predictions fail after error closure.

\item \textbf{Internal inconsistency}:
If the $C_{\text{red}}$ factors required for different observables
are mutually incompatible.
\end{enumerate}

\subsection{What Would NOT Falsify EDC}

\begin{itemize}[nosep]
\item Single prediction off by $\sim 10\%$ (within error envelope)
\item [I] pattern not upgrading to [Der] (was never claimed)
\item Need to refine postulates (normal theory development)
\end{itemize}

\subsection{Current Status}

\begin{statusbox}{Falsification Status}
\textbf{As of this writing}:
\begin{itemize}[nosep]
\item \textbf{No predictions in tension} (all within error envelopes)
\item \textbf{Framework not falsified} (no structural contradictions)
\item \textbf{Validated pending error closure} (awaiting OPR completion)
\end{itemize}

\textbf{Strongest constraints}:
\begin{itemize}[nosep]
