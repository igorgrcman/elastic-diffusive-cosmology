11.4.4       Normalizability Conditions (Domain-Dependent)
Why normalizability matters. A physical mode must have finite probability: |f (ξ)|2 dξ <
                                                                              R

∞. Whether a profile is normalizable depends on both the mass function m(ξ) and the domain.

Half-line domain (ξ ∈ [0, ∞)). On the half-line (our working assumption), normalizability
requires:                R∞
   • fL : Normalizable if 0 m(z ′ ) dξ ′ → +∞ as ξ → ∞ (the integral diverges, so fL → 0 fast
      enough).
   • fR : Not normalizable because the exponential grows without bound.
With m(ξ) > 0 for all ξ > 0, the left-handed mode is the only normalizable zero mode.

Finite interval (ξ ∈ [0, ℓ]). On a finite interval, both profiles are formally normalizable (inte-
grals are finite). However, the boundary conditions at ξ = ℓ determine which modes survive:
   • Dirichlet at both ends: Discrete spectrum; chirality selection depends on mode number
      parity.
   • Orbifold (S 1 /Z2 ): Reflection symmetry can project out one chirality entirely.
The finite-interval case is addressed in the BVP work package (Chapter 15).

        Key result: With the EDC mass profile (positive, rising into bulk) on the half-line

        modes delocalize into the bulk and do not participate in brane-localized interactions.
